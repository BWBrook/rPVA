# Woodhen PVA (KPZ308)

An R-based practical replacing VORTEX for the Lord Howe Island woodhen case-study.

* **Engine**: popbio + custom stochastic extensions  
* **Delivery**: learnr tutorial served from Posit Cloud  
* **Licence**: MIT (see `LICENSE.md`)  

## Directory map
- `R/` – simulation and helper functions  
- `data/` – YAML scenario files  
- `tests/` – testthat unit tests  
- `docs/` – worksheets, cheat-sheets, etc.
