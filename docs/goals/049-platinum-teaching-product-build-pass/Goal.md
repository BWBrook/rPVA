# Goal 049: Platinum Teaching Product Build Pass

## Objective

Lift the KPZ308 rPVA teaching package from a strong Practical 1 prototype to a
coherent two-practical teaching product with an assessment bridge: Practical 1
concept learning, Practical 2 Woodhen management application, and AT1 report
scaffolding.

## Desired outcome

- Practical 1 gives students a guided, app-led PVA concept path with evidence
  exports and optional landing-card deep dives.
- Practical 2 gives students a bounded Woodhen Management Lab surface over the
  existing Woodhen scenarios and one-factor sensitivity examples.
- Assessment materials connect app/R outputs to conservation advice writing.
- Instructor and teaching docs describe the two-week learning arc accurately.
- Local validation and browser evidence support the result before any later
  remote image promotion.

## Scope

- Local repo changes in app/API/tests/docs.
- Practical 1 interpretation and comparison affordance polish.
- Practical 2 teaching API and first Shiny app surface.
- Assessment brief, report scaffold, feedback, and delivery-doc alignment.
- No live ITS, Gitea, Docker registry, Moodle, or student-release changes.

## Non-goals

- No science/YAML/model-default changes.
- No Practical 2 research-grade Woodhen analysis beyond the existing teaching
  scenarios.
- No KPZ314 implementation.
- No remote deployment or image promotion.
- No direct external contact.
