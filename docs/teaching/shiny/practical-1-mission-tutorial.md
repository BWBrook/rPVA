# Practical 1 Mission Tutorial

## Purpose

Practical 1 is an app-led introduction to population viability analysis (PVA).
Change one ecological assumption at a time, inspect what changed, compare
possible futures, save evidence observations, and write a final synthesis. The
app is the main teaching surface; the worksheet is a light backup prompt.

## Class shape

The class lasts three hours. Approximately one hour is PVA teaching and GUI
introduction, followed by approximately two hours of guided, self-paced app
work while the instructor circulates to answer questions.

| Time | Mode | Purpose |
| --- | --- | --- |
| First hour | Teaching and GUI introduction | Frame PVA, run the baseline, and locate risk, abundance, and uncertainty. |
| Next two hours | Guided self-paced app work | Complete the Core route, build the evidence set in Compare, and explore further if time allows. |

## Your route through Practical 1

Start with the five **Core** model missions: Baseline compass, Island ceiling,
Individual chance, Environmental variability, and Rescue attempt. Then go to **Compare**
and build a three-run evidence set containing baseline, one risk mechanism, and
one intervention or vortex run.

When the Core route is complete, **Explore Further** remains available for
genetic pressure, catastrophes, the extinction vortex, advanced controls,
alternative comparisons, and optional plot downloads.

This browser session is temporary. Before closing the tab, use **Transfer** to
download both Current files: the comparison CSV and the evidence notebook
Markdown file. Refreshing, closing the tab, or allowing the session to expire
clears in-app run history, selection, notebook observations, and synthesis.

## Core mission guide

Complete these five model missions in order. Each mission asks for one visible
change and one comparison with the evidence already collected.

1. **Baseline compass** — on Start, click `Start baseline`. Keep this explicit
   student run as baseline run 1.
2. **Island ceiling** — run carrying capacity and look for trajectories that
   flatten near a habitat ceiling.
3. **Individual chance** — run demographic stochasticity and inspect how
   replicate paths spread.
4. **Environmental variability** — run environmental stochasticity and compare the
   uncertainty interval as well as the median.
5. **Rescue attempt** — run the intervention and ask whether abundance, risk,
   uncertainty, or more than one output changed.

After the fifth mission, go to Compare. The Core completion destination is a
three-run evidence set: baseline, one eligible risk mechanism, and one
intervention or vortex run. The full session history remains available in a
collapsed audit panel, while the outcome matrix keeps those three runs central.

## Explore Further

These optional activities remain available without completing a mission lock:

- genetic pressure;
- catastrophes and rare bad years;
- the extinction vortex;
- advanced risk controls;
- alternative selected comparisons; and
- optional trajectory, summary, or risk plot downloads.

Use them to ask a sharper question or substitute an eligible extension run in
Compare. They do not replace the five Core missions for the minimum route.

## Evidence and session recovery

In Compare, choose a focused three-run set. Write what that comparison shows
and select `Add to notebook`. Change the risk or action selection and save more
observations when they add useful evidence. Then write a final synthesis across
your strongest observations.

Move to Transfer and download the comparison CSV and evidence notebook. Both
must say `Current`; changing a selection, observation, or synthesis makes an
earlier download stale.

The session is temporary. Refreshing the page, closing the tab, or allowing
the session to expire clears in-app history, selected evidence, notebook
observations, and synthesis. Keep both downloaded files locally.

Practical 1 is unassessed practice. The same question-to-synthesis workflow
prepares you for the independent Practical 2 Woodhen investigation and its
report worth 25% of the unit.

## Instructor prompts

Ask students:

- What changed, exactly?
- Which output moved: extinction risk, abundance, uncertainty, or a mixture?
- What evidence supports that statement?
- What caveat prevents overclaiming?

Keep Practical 1 focused on comparing mechanisms and interpreting uncertainty.
Later practical work can use these habits in its own context.
