# Practical 1: PVA Mission

Start here: open the Practical 1 PVA mission launch page, the mission
worksheet, and the Practical 1 app link supplied for this class session.

Before you begin, create a folder called `practical-1-evidence` somewhere easy
to find. Save app downloads and fallback notes there.

Work through the missions by changing one visible setting at a time, comparing
each result with baseline run 1, and recording short notes in the worksheet.

Before you leave, save both evidence files from Compare:

- `practical1-comparison-YYYYMMDD.csv`
- `practical1-evidence-notes-YYYYMMDD.md`

If the app link, app speed, or downloads do not work after one retry, tell your
demonstrator and follow the fallback instructions for the same ecological
questions.

Keep the evidence files and worksheet notes for the Practical 1 wrap-up and
later Woodhen management practical.
