# Practical 1 Moodle-Ready Bundle

This folder is the compact handoff surface for assembling the Practical 1 PVA
mission in Moodle or a local class folder. It references the accepted teaching
sources rather than duplicating them.

## Use This Bundle For

- Moodle section labels and paste text:
  `moodle-section-text.md`.
- Upload and visibility decisions:
  `manifest.md`.
- Student start-here source:
  `../practical-1-student-launch-page.md`.
- Student worksheet source:
  `../practical-1-mission-worksheet.md`.
- Instructor support:
  `../practical-1-day-of-class-pack.md`,
  `../practical-1-go-no-go-checklist.md`,
  `../practical-1-fallback-pack.md`, and `../troubleshooting.md`.

Generated DOCX/PDF files are not committed in this bundle. Regenerate them
from the current repo state using the commands in `manifest.md`, then upload
the generated copies to Moodle if Barry wants file attachments rather than
Markdown pages.

## Student-Visible Items

Make these visible to students once the class route decision is green:

- Start here: Practical 1 PVA mission.
- Practical 1 mission worksheet.
- Practical 1 app link supplied for the class session.
- Optional report scaffold, only if the report-writing activity is planned for
  the same class.

## Instructor-Only Items

Keep these hidden from students unless a demonstrator needs them:

- Practical 1 day-of-class pack.
- Practical 1 go/no-go checklist.
- Practical 1 fallback pack.
- Troubleshooting guide.
- Expected outputs.
- This bundle manifest.

## Route Gate

Do not publish a raw-IP, insecure HTTPS, browser-warning, or unapproved route
as the student app link. The launch page and Moodle paste text deliberately
refer to the approved Practical 1 app link supplied for the class session.

Hosted student URL release remains separate from this packaging bundle. Local
or in-room teaching can be green while hosted URL/TLS/student-release remains
no-go.

## Ready For Barry-As-Student Roleplay When

- Barry has the start-here page or Moodle section text.
- Barry has the mission worksheet or a note-taking equivalent.
- Barry has an approved local or class app route for the roleplay session.
- Barry knows to save the comparison CSV and evidence-notes Markdown.
- The orchestrator has a short note-capture template for Barry's observations.
