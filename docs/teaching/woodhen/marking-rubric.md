# Marking Rubric — Woodhen Practical Report

Total: 100 marks

| Criterion | Excellent (100%) | Good (80%) | Adequate (60%) | Limited (0%) | Weight |
|---|---|---|---|---|---:|
| Practical 1 understanding | Explains all mechanism steps, plots, and changes in uncertainty with clear ecological links | Explains most mechanism steps and trends with minor omissions | Identifies basic mechanisms but weak causal links | Confused mechanism interpretation | 20 |
| Workflow reproducibility | Runs all required commands, records outputs, and uses fixed seed appropriately where required | Mostly complete command log with minor missing checks | Runs some steps but incomplete reproducibility trail | Commands missing or incorrect for core tasks | 20 |
| Woodhen scenario comparison | Correctly compares all core scenarios and interprets trade-offs across PE and abundance | Correctly compares most scenarios with some interpretation gaps | Limited scenario interpretation | Minimal or incorrect comparison | 20 |
| Sensitivity exercise | Fully bounded one-factor variation with ecological justification and clear reporting | One-factor variation mostly respected with valid interpretation | Runs multiple changes or weak justification | Fails bounded condition or no interpretation | 20 |
| Reporting quality | Short report is structured, evidence-led, and includes assumptions + caveats + recommendation | Good report but one section under-developed | Partial, report-like but lacks key components | Unclear or missing conclusion | 20 |

## Suggested badge thresholds

- 90–100: Road-test ready for class trial
- 75–89: Ready with minor instructor support
- 50–74: Needs one refinement cycle
- <50: Rework required before teaching use
