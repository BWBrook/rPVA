# Using your Evidence Portfolio

The project keeps your full working record: completed runs and any notes you
saved in Calibrate or Investigate. The Evidence Portfolio contains only the
items you explicitly add to a working portfolio. It does not judge how many
items you keep or which items you later use.

## Add from your project

Use **Add from project** to find saved project notes and completed Calibrate
results. A Calibrate result set includes its population trajectory, risk,
extinction timing, and result summary. The compatible 1980 comparison is also
available once all three historical management cases have been run.

Adding a saved note links the original student-authored note. It does not copy,
rewrite, or remove it from the project.

## Add evidence in Compare

Compare is where you inspect matched scenarios and interpret their results. Use
the direct save actions there to add the current plot, comparison table, or your
note to this portfolio.

Each saved item retains its comparison family, source runs, saved view, and
date. Model-generated plots and tables remain distinct from a student-authored
note.

## Organise the portfolio

Filter the library by evidence source or evidence type. You can preview an
item, change the portfolio order, or remove an item you no longer want to keep.
The portfolio order is stored with the project once the working project
connection is active.

## Choose an export

**Include in this export** is a separate, temporary choice. Use **Select all**
or **Clear export selection** when helpful, then arrange the selected items in
the order you want to preview them.

Items omitted from one export remain in your project portfolio. Export
selection is session-local in this first Evidence Portfolio gate; file output
is connected in the next output gate.

## Read provenance

Open **Scientific provenance** to see the evidence source, source scenarios,
saved view, and whether the item is model-generated or student-authored. If a
plot cannot be reconstructed from the compact project evidence, the portfolio
shows that limitation and retains the source metadata rather than substituting
example results.
