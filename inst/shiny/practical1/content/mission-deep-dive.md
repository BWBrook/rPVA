Practical 1 is a **guided concept lab**. Here you are learning how a PVA responds when one assumption changes.

Start with the **baseline as run 1**. That gives every later run a reference point. Then move through the Concept Lab: change one factor at a time, run the stage, and ask what changed in the outputs.

- **Create baseline run** creates the reference run.
- **Rerun baseline** only after changing projection years, mortality, or fecundity. Those successful working assumptions carry into later missions, while run 1 remains the pinned comparison.
- **Change one factor at a time** so your comparison has a clear, isolated cause.
- **Read risk first** using extinction and quasi-extinction plots, then use population trajectories to explain the pattern.
- **Use Compare** to evaluate the impact of different changes on the population.
- **Explain the trade-off** in plain language: which input or assumption changed, which output moved, and what caveat remains.

This is practice in PVA thinking: test an assumption, compare evidence, and interpret uncertainty before making a conservation claim.
