Practical 1 is a **guided concept lab**. You are not trying to find the "right" run; you are learning how a PVA responds when one assumption changes.

Start with the **baseline as run 1**. That gives every later run a reference point. Then move through the Concept Lab: change one factor at a time, run the stage, and ask what changed in the outputs.

- **Start baseline** creates the reference run.
- **Change one factor at a time** so your comparison has a clear cause.
- **Use Compare** to look across runs rather than trusting a single screen.
- **Explain the tradeoff** in plain language: which input or assumption changed, which output moved, and what caveat remains.

This is practice in PVA thinking: test an assumption, compare evidence, and interpret uncertainty before making a conservation claim.
